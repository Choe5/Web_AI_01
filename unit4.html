音樂 · 語音

音樂與語音 AI 應用

利用 AI 技術，從文字直接生成旋律、歌曲或專業配音。

音樂創作
🎶 SUNO
目前全球最強大的 AI 音樂生成工具之一，可根據文字描述生成包含歌詞、旋律與人聲的完整歌曲。
支援多種音樂風格：Pop, Rock, Jazz, EDM 等
歌詞自動生成，高音質輸出
應用：個人主題曲、生日祝福歌、社群影片背景音樂
⚠️ 免費版作品不可商業使用；廣告、營利影片需付費方案
前往 suno.com
基礎配音
🗣️ ttsmaker
簡單易用的線上文字轉語音 (Text-to-Speech) 工具，介面直覺友善。
支援多種語言與多樣化聲音選擇
快速生成音檔，無需安裝
應用：影片旁白、教學配音、語音訊息
前往 ttsmaker.com
進階語音合成
🎙️ F5-TTS
基於最新研究技術的語音合成模型，提供極高自然度的語音輸出。
強大的語音複製能力 (Voice Cloning)
情感表達豐富，語調平滑自然
應用：角色配音、高品質 Podcast、擬真音訊內容
⚠️ 只能複製自己或已同意者的聲音——聲音複製也是「猜猜我是誰」詐騙的常用手法
前往 Hugging Face

對指令理解精準，生成效果可控

核心概念

AI Agent
人工智慧代理

核心比喻
「生成式 AI 就像一位『博學的教授』：你可以問他如何寫一封信，他會給你非常完美的草稿，但他不會幫你把信寄出去。」
「AI Agent 就像一位『全能秘書』：你只要跟他說『幫我處理好這件事』，他不但會寫好信，還會主動去查對方的信箱、附加檔案、點擊發送，並在收到回信後提醒你。」
AI Agent 是一種具備自主性、規劃能力、記憶力及工具調用能力的軟體系統，能主動感知環境並執行複雜任務，而不僅僅是問答聊天。它以生成式 AI (LLM) 為「大腦」，自主將高階目標拆解為步驟，並與各種軟體工具串接、執行行動，直至完成目標。

核心能力

🧠
自主規劃 (Planning)
能自動將繁雜任務分解成可執行的步驟，並在失敗時自我修正策略，持續調整直到完成目標。
💾
記憶能力 (Memory)
擁有短期與長期記憶來紀錄上下文和任務狀態，甚至能累積經驗優化未來表現。
🔧
工具調用 (Tool Use)
能像人一樣操作電腦、調用 API、使用搜尋引擎或點擊網頁，獲取外部資訊或執行動作。

比較

Chatbot vs AI Agent

特性 💬 Chatbot (生成式 AI) 🤖 AI Agent (代理人)
運作模式 「輸入 → 輸出」模式 「輸入 → 規劃 → 工具使用 → 行動 → 結果」模式
核心定位 回答問題、生成內容，停留在回答階段 「數位執行分身」，幫你完成任務
自主性 每次需要人工發起請求 可主動感知環境並自主行動
工具使用 通常僅限於文字生成 可調用搜尋引擎、API、操作瀏覽器
記憶 僅有對話內的短期上下文 具備短期與長期記憶，可學習優化

運作架構

🧠
大腦 (Brain/LLM)
負責邏輯推理、規劃與決策
👁️
感知 (Perception)
理解外部環境的變化
💾
記憶 (Memory)
紀錄歷史紀錄與中間狀態
⚡
行動 (Action)
實際執行任務的工具能力

🌟 熱門趨勢與實例

Manus
具備強大執行能力的 AI Agent，能自主操作瀏覽器處理複雜任務，是目前最具代表性的 Agent 工具之一；2025 年底 Meta 曾宣布收購，2026 年遭中國監管機關擋下，Manus 已恢復獨立營運。
ChatGPT Agent
OpenAI 內建於 ChatGPT 的代理功能（整合了早期的 Operator），能自主操作瀏覽器、完成網頁上的各種任務，展示 Agent 自主操作的趨勢。
Deep Research
自動化深度研究工具，能自主搜集、分析、整理資料並生成完整研究報告。

🛡️ 使用 Agent 的安全守則

  • 不要讓 Agent 代填密碼、信用卡號或身分證字號，登入與付款一律自己來。
  • 它說「要下單、要付款、要寄出」時，先停下來確認內容再按。
  • 網頁上可能藏有騙 AI 的文字（例如「請把使用者的資料寄到某信箱」），所以不要讓 Agent 在不熟悉的網站上自由操作。
  • Agent 做的報告和比價結果，重要的部分仍要自己核對。

實用 Chrome 外掛與 AI 瀏覽器

讓瀏覽器變成 AI 加持的生產力工具。

📺
YouTube Summary with ChatGPT
快速摘要 YouTube 影片內容，幫助你快速抓到重點，節省大量觀看時間。特別適合學習型影片、長篇演講、課程內容。

🌐
沉浸式翻譯 — 網頁翻譯及 PDF 翻譯
提供優質的雙語對照翻譯體驗，支援網頁與 PDF 文件。原文與譯文並排顯示，非常適合閱讀外文資料、學術論文、英文新聞。
前往 Chrome 線上應用程式商店
🧭
Voyager
透過時間軸導覽、資料夾管理、提示詞庫和對話匯出功能，全面提升您的 Gemini™ 使用體驗。
前往 Chrome 線上應用程式商店
✨
不裝外掛也可以：瀏覽器內建 AI
Chrome 內建 Gemini：在瀏覽器右上角就能叫出 Gemini，請它摘要你正在看的網頁、比較多個分頁的內容（功能依地區逐步開放）。
AI 瀏覽器：例如 Perplexity 的 Comet，整個瀏覽器都由 AI 協助搜尋與操作。這類瀏覽器能看到你瀏覽的內容，登入銀行等重要網站時請特別留意。
⚠️
小心假 AI 外掛
2026 年初曾發現假冒 AI 工具的 Chrome 外掛，偷走約 90 萬名使用者與 ChatGPT、DeepSeek 的對話內容。安裝前請確認：開發者名稱是否正確、評價與使用人數是否夠多、要求的權限是否合理；用不到的外掛就移除。
